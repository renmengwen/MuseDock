MuseDock 是一个本地优先的 AI 短视频创作与编辑工作台。它将素材整理、脚本与分镜、配音字幕、画面生成、视频渲染和后续修改集中在同一个创作流程中，目前支持 **HyperFrames 动态视频** 与 **线稿白板动画** 两种创作模式。

项目会保留素材来源、制作过程和阶段产物，方便查看进度、修改内容、失败恢复和继续编辑。任务、模型配置、素材、音频、工程和导出文件默认保存在本地；只有在调用已配置的模型、联网研究、素材或来源服务时，才会发送相应请求。

## 快速开始

### 环境要求

- Node.js `>=22 <23`
- Python 3.10+
- Google Chrome
- `ffprobe`

采集和渲染会复用系统安装的 Chrome。项目依赖中已包含 `ffmpeg`，也可以使用系统中的版本。Python 用于线稿白板动画的媒体处理，但统一初始化时会一并准备它的环境。

### 安装并启动

```powershell
npm install
npm run dev
```

`npm install` 会安装 Node.js 依赖，并自动创建线稿白板动画所需的独立 Python 媒体环境。无论计划使用哪种模式，首次安装都完成这两部分初始化。之后打开 <http://localhost:5173>，即可在同一个创作首页选择 HyperFrames 动态视频或线稿白板动画。

首次进入应用后，请在设置中心至少配置一个分析模型。配音、图片生成和联网补图功能还需要按需配置 TTS、图片模型和 Pexels。

## 创作模式

| 模式 | 支持输入 | 制作方式与结果 |
| --- | --- | --- |
| **HyperFrames 动态视频** | 选题、文章、公众号、GitHub、抖音链接、图片 | 整理来源和素材，生成脚本、配音、字幕与动态镜头，输出可继续修改的 HTML 视频工程。 |
| **线稿白板动画** | 主题、正文、带时间轴的 SRT 字幕 | 确认内容与分镜后，按设置生成旁白或无旁白时间轴、场景线稿与连续落墨动画，最终输出视频。 |

## 核心能力

- **多种内容入口**：可以从选题、文章、链接、图片、正文或 SRT 字幕开始创作。
- **来源与素材管理**：保留原始来源和研究结果，将文章图片、生成图片与补充素材分别管理，便于追踪和调整。
- **素材驱动的动态视频**：HyperFrames 根据内容和素材规划画面，生成 HTML/CSS/GSAP 镜头，并完成配音、字幕、音效、渲染与合成。
- **可编辑的视频工程**：在工程编辑器中修改文案和布局、检查画面、让 AI 调整镜头并重新导出。
- **连续落墨的白板动画**：支持横屏与竖屏、六种暖米黄纸底视觉模板、画笔显隐、字幕烧录、旁白与静音方案。
- **可观察、可恢复的长任务**：在任务详情中查看阶段进度、预览和待确认事项；失败后可以复用仍有效的产物继续制作。
- **本地数据优先**：创作数据默认保存在本机，便于自行管理和备份。

## 基本流程

### HyperFrames 动态视频

```text
选题 / 链接 / 图片
  -> 来源与素材准备
  -> 内容策划、旁白与分镜
  -> 动态画面、字幕与音效
  -> 渲染、质检与导出
  -> 在工程编辑器中继续修改
```

### 线稿白板动画

```text
主题 / 正文 / SRT
  -> 内容、分镜与制作方案
  -> 用户确认
  -> 旁白或无旁白时间轴
  -> 场景线稿与连续落墨动画
  -> 预览、确认与导出
```

白板模式支持简体中文、美国英语和英国英语旁白，也可以完全关闭旁白。主题与正文可以选择保留原文或在不改变事实的前提下润色口播；SRT 模式会保留输入时间轴。更详细的模型要求、视觉模板、语音配置和恢复说明见[白板制作说明](./server/resources/whiteboard/README.md)。

## 抖音转写

点击左侧栏的 **抖音转写**，粘贴公开视频链接或分享文案，即可提取完整文字和句级字幕。启用自动校订后，应用会调用已配置的分析模型，并分别保留原始版、校订版和修改记录；结果可下载为 TXT 或 SRT。

每次转写会单独保存在本机。工具左侧的 **转写历史** 支持按视频标题或链接搜索、按状态筛选；选择记录即可重新查看和下载原始版或校订版。点击 **新建转写** 开始下一条，旧记录会继续保留；刷新页面或重启服务后也可找回已有历史。转写进行中可以查看其他记录，不影响后台处理。

默认使用本地 FunASR 服务，无需添加供应商或填写 API Key。安装一次 Python 依赖后，开始转写时会检测服务并按需在后台启动；已有环境和模型缓存可在全局 ASR 设置中指定，电脑重启后也无需手动拉起服务。安装与使用方法见[抖音转写与 FunASR 说明](./server/resources/funasr/README.md)。

## 使用边界

- MuseDock 仍处于早期开发阶段，功能和数据结构可能继续调整。
- 采集能力只服务于短视频创作，不是通用爬虫工具；文章和 GitHub 来源只处理正文和图片，不提取网页中的视频。
- 分析模型、图片模型、TTS、联网研究、Pexels 和来源平台均受各自服务配置、网络和配额限制。
- HyperFrames 渲染依赖 Chrome；视频合成依赖 `ffmpeg` 和 `ffprobe`；白板模式还依赖独立的 Python 媒体环境和可用字体。缺少相关依赖时，对应的渲染或导出功能将不可用。
