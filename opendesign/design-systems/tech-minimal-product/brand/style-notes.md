# Style Notes

## 布局

- 全局框架采用左侧浅色任务区 + 主工作区。首页和任务页保留任务历史侧栏，设置页保留分区导航。
- 主工作区最大宽度不做窄版限制，视频编辑和设置表单都需要横向空间。
- 面板之间使用 12-20px 间距。重复列表项使用 8-12px 内边距。

## 颜色

- 系统底色使用原版浅灰白，不再使用大面积深色背景。
- 浅色内容面板使用白色或近白色，边框比阴影更常用。
- 主按钮和关键激活状态使用 MuseDock 红，青色只做辅助信号、徽标和轻提示；系统提醒使用琥珀，破坏性操作使用红色。

## 字体

- 中文和英文统一使用系统 UI 字体栈。
- 任务 ID、事件 ID、路径和代码使用等宽字体。
- 页面标题不超过 36px；工具栏和卡片内标题保持 13-20px。

## 组件

- 按钮高度 32-40px；图标按钮 32px。
- 表单控件高度 36-40px；文本域最小高度根据用途设置。
- 通用卡片圆角最大 8px，不使用套卡片；首页主输入器沿用原版较大的圆角输入框。
- 状态 chip 可以使用圆角胶囊，但不用于普通操作按钮。

## 动效

- 只使用 120-180ms 的 hover、focus、active 状态。
- loading 图标可以旋转；页面不做复杂入场动画。
- 画布和帧条交互优先稳定，不使用会影响定位判断的动画。
