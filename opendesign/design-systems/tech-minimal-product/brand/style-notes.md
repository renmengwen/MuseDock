# Style Notes

## 布局

- 全局框架采用左侧浅色任务区 + 主工作区。首页和任务页保留任务历史侧栏，设置页保留分区导航。
- 主页保持干净居中的创作入口，不为了科技感额外增加仪表盘模块；任务详情保持状态、进度、预览、恢复建议的既有结构。
- 主工作区最大宽度不做窄版限制，视频编辑和设置表单都需要横向空间。
- 面板之间使用 12-20px 间距。重复列表项使用 8-12px 内边距。
- 设置页主视图优先展示摘要列表和关键状态；供应商、模型、系统路径等字段多的低频编辑进入弹框。

## 颜色

- 系统底色使用原版浅灰白，不再使用大面积深色背景。
- 浅色内容面板使用白色或近白色，边框比阴影更常用。
- 不把 MuseDock 红和青当页面骨架。默认使用灰白黑；红色只用于删除、失败、不可恢复等警示语义，不用于普通主操作；青色只用于 focus ring 和极少量轻状态信号。
- 科技感来自精确的层级、细线、密度和状态反馈，不靠大面积霓虹渐变或发光装饰。
- 深色只用于视频编辑器、源码、终端感日志和需要聚焦的工具区域；普通任务、设置和长表单保持浅色控制台。

## 字体

- 中文和英文统一使用系统 UI 字体栈。
- 任务 ID、事件 ID、路径和代码使用等宽字体。
- 页面标题不超过 36px；工具栏和卡片内标题保持 13-20px。

## 组件

- 新增通用控件优先使用 Tailwind CSS utility class 与官方 `shadcn/ui` 组件；不要继续向 `frontend-react/src/styles.css` 追加大段全局样式。
- 按钮高度 32-40px；图标按钮 32px。
- 表单控件高度 36-40px；文本域最小高度根据用途设置。
- 通用卡片圆角最大 8px，不使用套卡片；首页主输入器沿用原版较大的圆角输入框。
- 状态 chip 可以使用圆角胶囊，但不用于普通操作按钮。
- 可用等宽数字、紧凑状态条、细分割线、微弱青色 focus ring 表达科技感；不要使用 AI 头像、魔法星光、漂浮光球或“智能中枢”插画。

## 动效

- 只使用 120-180ms 的 hover、focus、active 状态。
- loading 图标可以旋转；页面不做复杂入场动画。
- 画布和帧条交互优先稳定，不使用会影响定位判断的动画。
