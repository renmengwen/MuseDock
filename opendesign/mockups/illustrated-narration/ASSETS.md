# 设计预览素材来源

- PNG 截图：本任务中的 MuseDock React 实现；由隔离浏览器测试生成，画面数据和模型返回均为本地夹具。
- 视频中的摄影素材：OpenCV 项目 4.x 分支的 samples/data/fruits.jpg。来源为 https://raw.githubusercontent.com/opencv/opencv/4.x/samples/data/fruits.jpg ，同仓库的许可证副本见本目录 OpenCV-LICENSE.txt。
- 视频旁白：Windows SAPI 本机离线中文语音，仅作为本地固定音频测试素材；没有请求真实配音供应商。
- 视频字幕：这组本地固定素材采用计划分配的显示时间，不冒充供应商原生字幕或 ASR 结果。
- 视频由新模式的 25 fps 渲染器实际编码，包含三种画幅和轻微运镜。这些素材不构成真实供应商模型、图片风格、读音或运动观感的人类批准。

原始素材 SHA、具体轨迹、编码及解码信息保存于本任务本地的 docs/verification/illustrated/real-media/provenance.json。
